Managed Cloud AI

NOT YET AVAILABLE Future managed AI service.

← AI Analyst
☁️ Managed Cloud AI would be the easiest user experience — but it has the highest infrastructure and data-governance responsibility for us.

What Managed Cloud AI would mean

You would use AI without creating your own provider key. CRM Intelligence would operate a secure backend or AI gateway that authenticates users and communicates with an approved AI provider.

  • Provider credentials would be held server-side, never in public browser code.
  • Requests would pass through a controlled backend/gateway rather than directly exposing a shared master key.
  • Authentication, authorization and rate limiting would be required.
  • Usage monitoring, quotas and cost controls would be required.
  • Cloud processing and third-party data handling would need to be clearly disclosed and governed.

Why isn't Managed Cloud AI enabled yet?

Our current application is intentionally static and browser-first. A managed AI service would require additional infrastructure, security engineering, identity management, provider agreements, monitoring and careful treatment of customer business information.

We will not enable this simply by placing a provider API key in the GitHub Pages application.

What the future experience could look like

1. User asksQuestion entered in the familiar AI Analyst interface.
2. Browser prepares contextCRM Intelligence sends only the information selected for AI analysis.
3. Secure gatewayOur backend authenticates and applies provider/security controls.
4. AI providerThe approved cloud model processes the request.
